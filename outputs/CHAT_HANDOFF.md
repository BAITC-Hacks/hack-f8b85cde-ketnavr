# Передача ИИ-помощника

Чат интегрирован поверх актуального `main`, без замены приложения старой копией.
Калькулятор, загрузчик Excel, таблица, пагинация, фильтры, полный расчёт,
экспорт и журнал ошибок сохранены. Новых npm/Python-зависимостей нет.

## Для бэкендера

1. Сохраните свои локальные изменения и получите актуальный `main` обычным
   fast-forward (`git pull --ff-only origin main`). Не используйте force/reset.
2. Пересоберите frontend по `SHARING.md` (`cd frontend`, `npm install`,
   `npm run build` с API-настройками сборки).
3. Для локального чата достаточно уже настроенного AI-провайдера и архива
   в `backend/.env`; перезапустите `app.main`.
4. Для общей ссылки чат включается отдельно: `SHARE_CHAT_ENABLED=true`
   в `backend/.env`, затем перезапуск `app.share`. Этот процесс тоже должен
   иметь настройки провайдера. По умолчанию публичный чат выключен.
5. Убедитесь, что `/api/health` показывает `chat_enabled: true`. Флаг означает
   разрешение чата, а не проверку валидности ключа или доступности провайдера.
6. Если владелец данных и ключа разрешил платную проверку, отправьте один
   вопрос через «Спросить ИИ». Проверьте ответ и неизменность таблицы.

Чат отправляет вопрос, историю и ограниченную часть расчёта AI-провайдеру.
Каждый вопрос может расходовать токены; обновление таблицы на общей ссылке — нет.
Отключить чат можно флагом `SHARE_CHAT_ENABLED=false` и перезапуском `app.share`.
Публичного входа по паролю нет: нужны отдельные меры для постоянного продукта.
Подробности, ограничения и передаваемые данные описаны в `SHARING.md` и
`outputs/API_CONTRACT.md`. Ключи на фронт не передавать.

## Проверки интеграции

- Frontend: `npm test` — 28 тестов, включая 7 новых проверок API чата.
- Backend: `.venv/Scripts/python -m unittest discover -s tests` — 24 теста,
  включая 10 новых проверок контекста, входных данных, ошибок, fallback,
  ограничений частоты и неизменности сохранённого расчёта.
- `npm run build` — production-сборка.
- Изолированный браузерный стенд `node tests/qa-server.mjs`: синтетические
  данные, страница 2 таблицы, отправка вопроса, восстановление черновика после
  503, длинный ответ и продолжение истории, ожидание, Escape, повторное открытие,
  мобильный экран 390×844 и горизонтальный 844×390.
- Ни один проверочный запрос не обращался к платному AI API. Живой ответ с
  реальным ключом и актуальность временного туннеля требуют проверки владельцем
  сервера после обновления. Качество ответов модели заглушками не проверяется.

На основном API чат читает полный расчёт; на сервере показа — его сохранённый
снимок. Сводка глобальная, не по фильтрам пользователя; деталей модели доступно
не более 18 строк. Чат не меняет количества и не отправляет заказы.
